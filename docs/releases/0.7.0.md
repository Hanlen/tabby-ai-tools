# 0.7.0

AI Tools settings now scroll with the full settings page across connections, workflows/preferences and scheduled tasks. The editor no longer constrains forms to a fixed-height nested scroll area, including in narrow windows. Smaller headings and tighter general-settings spacing leave more room for configuration content. Connection cards and editor summaries use two compact rows, with smaller provider icons and less padding; names can still wrap when needed.

Readable activity, sidebar keyboard isolation and terminal read improvements are included in [v0.6.0](0.6.0.md).

Pointer interactions no longer leave thick focus outlines on sidebar controls (including History, Context, model selection, workflows and schedules) or AI Tools settings. Native control focus is handled by the browser so clicking from the prompt does not inherit a keyboard focus ring. Keyboard navigation uses a consistent thin indicator; conversation text selection remains frameless, with copying and terminal shortcut isolation preserved.

Interactive `/remember` recordings now preserve stdin/key/attachment intent and structured sidebar questions, with conditional policies, a bounded local runner and current-connection helper decisions. Workflow settings configure the helper model and advanced policies. Helpers are isolated from terminal writes and foreground model settings, account usage to the parent Goal, and cancel with Stop. Fresh observations and unknown-result journals prevent automatic command/answer replay; missing machine verification returns to the main model. v1 libraries remain readable, v2 runs support rebind-before-resume. Documentation, bundled model guidance and the SVG/PNG illustration describe the new workflow route. No real provider or desktop/SSH validation is implied by offline fixtures.

The conversation Stop button now uses the theme’s filled danger style by default.
