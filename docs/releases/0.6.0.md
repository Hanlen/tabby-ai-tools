# v0.6.0 — Readable activity and safe sidebar copying

Thinking and terminal tool activity now stream into collapsed conversation entries. Expand an entry to inspect service-returned thinking text, tool arguments and results while ordinary replies stay visible. Expansion survives streaming updates, and saved activity is available when reopening a session. Thinking display segments are capped at 32,000 characters without altering the provider's native context.

Sidebar keyboard events no longer reach the active terminal's global hotkeys. Selecting message text moves focus out of xterm while preserving native selection, copy, paste, prompt shortcuts and Tab navigation. Ctrl+C in the terminal itself retains its normal interrupt behavior.

Codex explicitly requests reasoning summaries, and supported OpenAI reasoning requests enable readable summaries. Empty or encrypted-only reasoning events no longer create cards stuck on “Waiting for displayable content…”, including after history restore. A readable summary still depends on the model and service returning one; unavailable internal reasoning is never reconstructed.

Terminal reads now return early when shell integration reliably confirms that a controlled single command has completed. A short rendering buffer precedes readback. Unknown completion, multiline intermediate prompts, cancellation and configured maximum waits retain their safeguards. Model-facing skill instructions and the generated knowledge bundle describe the maximum-wait behavior.

The English and Chinese READMEs, user/developer guides and SVG/PNG interface illustration are synchronized for v0.6.0. The robot GIF and reduced-motion image are preserved. Bundled SDK dependencies and the existing Electron runtime remain compatible with installation without system Node.

Local Linux / Node 22.19.0 validation covers 783 tests (777 passed, six Windows-only skips), skill bundle/check, type checks, production builds and actual tarball installation with no node on PATH and lifecycle scripts enabled. A Chromium fixture reproduces the original copy/interrupt leak and verifies native clipboard operations, selection, local shortcuts, keyboard navigation, terminal shortcuts and listener cleanup after the fix. Final branch/tag Linux, macOS and Windows CI results and the exact reviewed tarball SHA-256 are recorded in the GitHub Release.

No paid model request was made. These checks do not establish real provider latency, universal availability of thinking summaries or complete Tabby desktop/SSH validation on every platform.
