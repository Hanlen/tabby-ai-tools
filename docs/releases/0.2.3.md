# Tabby AI Tools 0.2.3

AI Tools now opens automatically when Tabby starts, so the default local Codex connection is available without first changing Settings.

- Enable startup opening for new configurations and existing configurations without a saved startup preference. Preserve an explicit opt-out and the toolbar button for manual opening.
- Retain readiness ordering, deferred sidebar mounting, directory selection, and the one-time startup behavior.
- Update both README editions, the user/developer guides, and the bundled model-facing skill to describe the default and how to disable it.
- Refresh the editable SVG and exported PNG interface illustration with the default-on setting and release version. Upgrade the header robot GIF and reduced-motion PNG fallback from 512 × 256 to 1024 × 512, preserving the twelve-frame loop and compact README display. Record the high-definition generation and encoding process.

Validation: bundled skill generation and consistency, TypeScript checks, automated tests, production build, diff whitespace, GitHub-rendered bilingual README headers, illustration/animation inspection, and npm tarball contents and integrity. GitHub Actions runs the checks on Linux, macOS, and Windows; the release is gated on that matrix passing.

Limitations: a live Tabby desktop startup check and paid model smoke tests were not performed for this release.
