# Tabby AI Tools 0.3.2

Complete Codex executable discovery across macOS, Linux and Windows. Version 0.3.1 only added an older macOS bundle entrypoint; this patch also supports the current `ChatGPT.app/Contents/Resources/codex-cli/bin/codex` layout, the former `Codex.app` name, and both system and user Applications directories.

- Discover standalone package entrypoints under `CODEX_HOME/packages/standalone/current/bin`, with compatibility for the older `current` layout.
- Query installed Homebrew and npm for their global prefixes when ordinary locations do not contain Codex. Support configured prefix variables, Linuxbrew, Windows npm global shims and Node recovered through NVM.
- Use compatible Codex binaries from VS Code, Insiders and remote-server extensions only as a final fallback. Select valid entries by extension version and current OS/CPU architecture.
- Bound prefix queries to two seconds and 16 KiB, reject malformed output, and cancel their process trees on close or configuration changes. Keep explicit/custom command contracts and already-selected CLI priority.
- Update both READMEs, the full discovery matrix and development/validation notes, twelve settings translations, and the SVG/PNG overview. Preserve the robot GIF and reduced-motion fallback.

Validation: skill bundle generation/consistency, TypeScript, 501 local tests (495 passed, six platform skips), production build, whitespace checks, rendered bilingual Markdown, image inspection and actual npm tarball contents. Branch and tag publication require the Linux/macOS/Windows GitHub Actions matrix to pass. Tests cover each installation source, stale symlinks, custom prefixes, architecture/version filtering, invalid manager output, timeouts, cancellation and actual Windows npm.cmd-to-codex.cmd startup.

Limitations: source-layout fixtures and mock transports verify discovery and process behavior, not every installed desktop/IDE version. App/extension internals may change; an explicit executable path remains available. No live Tabby desktop/SSH end-to-end or paid model smoke tests were run.
