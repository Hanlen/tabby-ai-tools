# v0.9.0 — Image previews, terminal streams and task logs

Pasted image thumbnails now open a larger modal preview with keyboard access, window-aware sizing, Escape/close/backdrop dismissal and focus restoration. Removing the attachment or switching conversations closes its preview and releases cached URLs; delayed reads cannot restore a previous conversation's preview.

Terminal tools add cursor-based delta reads, bounded output/completion waits, and session-scoped local task logs with paginated reading and literal search. Settings can disable saving task terminal logs. Capture starts when a task reads or operates a terminal, stops with its owner/session, and excludes attachment transport payloads. Delta text preserves stream arrival order rather than reconstructing an interactive screen; take a fresh snapshot before interacting with a terminal application.

Expired sealed logs reclaim metadata capacity before new capture admission. Cleanup runs behind pending writes and preserves active captures and pinned readers. Delta reads retain the controlled-terminal 1,000 ms default; explicit `waitMs: 0` remains immediate. API compaction fixtures no longer unnecessarily start Pi; actual Pi runtime tests check their Node requirement and explain conditional skips. `npm run test:attachments` and `npm run test:terminal-logs` run focused regression checks without switching Node.

The bilingual README, guide, development notes, bundled model-facing skill/knowledge and synchronized overview SVG/PNG describe the final behavior. The robot GIF and reduced-motion static fallback are preserved. The overview is an illustration with example connections and tasks, not a desktop screenshot.

## Validation and limits

Release validation includes skill bundle/check, TypeScript checks, the full automated suite, production webpack/Pi builds, whitespace checks, exact-tarball contents/integrity checks and scripts-enabled installation with no Node on PATH. Branch and tag CI cover Linux, macOS and Windows; authoritative CI links and the verified tarball SHA-256 are recorded on the GitHub Release.

Local fixtures exercise immutable scoped caches, real local POSIX exec/PTY transfers, log retention/queued writes and delta wait defaults. A Chromium preview fixture checks small/desktop layout, modal focus and dismissal. These fixtures do not establish actual Tabby desktop clipboard, authenticated SSH or Windows/macOS desktop behavior. No paid model smoke requests are made. Logs can contain sensitive command output, be incomplete, expire or become unavailable; logging never proves command success. There is no screen replay, arbitrary regex, cross-session log search or automatic image delivery to Codex/sidebar models. No runtime dependency was added and plugin users do not need to install Node.
