# Tabby AI Tools 0.3.1

Fix automatic Codex discovery on macOS when the executable is bundled inside ChatGPT.app instead of being available on PATH. Discovery now checks `~/Applications/ChatGPT.app/Contents/Resources/codex` and `/Applications/ChatGPT.app/Contents/Resources/codex` after the existing Shell, NVM and common installation locations. Explicit paths, custom command names and existing PATH selections retain their priority and validation rules.

Update both READMEs, the troubleshooting and development guides, and the editable SVG/PNG overview with the current version and macOS discovery example. Preserve the animated header robot and reduced-motion fallback.

Validation: bundled skill generation/consistency, TypeScript, 469 local tests (464 passed, five platform skips), production build, whitespace checks, rendered bilingual Markdown, illustration/animation inspection and actual npm tarball contents. Branch and tag publication are gated on the GitHub Actions Linux/macOS/Windows matrix.

Limitations: local discovery tests use filesystem fixtures on Linux; they do not verify any particular ChatGPT.app installation or guarantee a stable internal bundle layout. No live Tabby desktop/SSH end-to-end or paid model smoke tests were run. For other application locations, configure the actual executable path in Settings → AI Tools.
