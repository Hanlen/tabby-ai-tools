# v0.9.1 — Terminal dispatch, CLI login recovery and Pi test stability

Ordinary terminal commands, stdin, Enter and process attachment now reach the terminal adapter when the workflow library is idle or disabled. An undefined workflow token is no longer mistaken for an active workflow. Active workflow helper-token budgets, cancellation isolation, checkpoint rules and terminal adapter checks remain enforced.

Private Codex and Claude Code spaces initialize missing login caches from available local ChatGPT/OAuth files. Existing private logins are preserved. Authentication warnings offer explicit cache replacement and reconnect while preserving conversations and input drafts without replaying tasks. Missing/invalid source caches leave the private cache intact; OS-keychain-only login still requires official selected-space authentication. Missing Codex rollouts are replaced only when no recoverable context exists; successful reconnect clears stale connection errors.

The repeated Pi compaction regression allows 90 seconds on every platform for ten sidecar turns. Windows diagnostics completed the unchanged assertions in about 33.4 seconds, exceeding the previous 30-second limit. Product compaction behavior and the history, summary-cost and resumption assertions are unchanged.

Both READMEs, the guide, development notes and synchronized overview SVG/PNG describe the patch. The overview uses example tasks and connections; it is an illustration. The robot animation and reduced-motion fallback are retained. The preceding CLI recovery commit already updated model-facing skill/knowledge and localized guidance. No tool schema or runtime dependency changed.

## Validation and limits

The release requires skill bundle/check, typecheck, the full automated suite, production webpack/Pi builds, whitespace checks and exact-tarball installation with scripts enabled and no Node on PATH. The GitHub Release records the actual results, branch/tag Linux/macOS/Windows CI links and verified tarball SHA-256.

Offline/local HTTP fixtures cover ordinary and active workflow dispatch, helper budgets, cancellation/replacement isolation and repeated compaction. The earlier CLI recovery checks include real local Codex account/cache recovery without inference and browser dialog fixtures; real Claude account recovery remains unverified. No paid model requests or new actual Tabby desktop/SSH or Windows/macOS desktop validation are included. CI evidence does not establish desktop behavior. Plugin users do not need a system Node installation.
