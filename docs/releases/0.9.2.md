# v0.9.2 — Native CLI installation recovery and SSH agent identity

Codex tool connections validate known Windows companion requirements before choosing a CLI version. Discovery, connection reuse and new-turn admission check installation health; explicit runtime helper failures cover files removed after preflight. One connection rebuild is allowed at a known idle boundary, preserving the original selector, session space, model, permissions and conversation. Concurrent turns, pending tool replies and unknown execution outcomes prevent unsafe replacement. Recovery never replays a task, tool call or terminal command. Older/unknown versions and npm/batch launchers retain their layout boundaries.

Claude local re-resolves the original configured CLI and rechecks its required flags and selected-space authentication before each invocation, including goal continuation. Preflight failure retains the last successful native session. Spawn failures and malformed authentication responses produce CLI/protocol diagnostics; only explicit logged-out status establishes logout. Submitted inference is never automatically retried.

Existing native agents in Linux SSH panes can be attached through an independent exec channel. PID, start time, foreground group and an output-only random PTY proof establish the target identity, repeated before every input. The probe sends no Agent input and does not restart it. Unsupported exec/procfs, nested SSH, multiplexers and unverifiable identities remain blocked. See [recovery behavior and limits](../codex-installation-recovery.md).

The bilingual README, guide, Claude/development documentation, model-facing skill/knowledge and synchronized overview SVG/PNG reflect this patch. The overview contains example connections and task output; the robot GIF and reduced-motion fallback remain available. Runtime dependencies and the default built-in Electron runtime are unchanged; ordinary installation requires no separate Node installation.

Validation requires skill bundle/check, typecheck, the full offline suite, production webpack/Pi builds, whitespace checks and installation of the exact release tarball with scripts enabled and no Node on PATH. The GitHub Release records the final results, branch/tag Linux/macOS/Windows CI and tarball SHA-256. The earlier implementation run passed 943 tests (937 passed, six platform skips); the release validation is recorded separately in VALIDATION.md.

Evidence includes simulated Codex/Claude processes, MCP tool round trips, bounded recovery, session retention and no replay, plus a real local Linux PTY proof without stdin writes. It does not establish actual Windows/macOS Tabby operation, the user's SSH pane, real Claude account access or paid model execution. No new paid model smoke test is performed. Future native CLI layout changes may require adapting the known companion rule.
