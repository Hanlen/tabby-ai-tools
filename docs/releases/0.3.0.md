# Tabby AI Tools 0.3.0

Terminal takeover now proceeds without a separate confirmation dialog. SSH and other terminals with unavailable foreground-process detection no longer repeatedly ask the user to confirm that the terminal is idle. The agent reads the visible output before proceeding; unavailable detection alone never sends Ctrl+C. Needed foreground tasks stay protected. Detected unrelated tasks can be interrupted automatically, with verification that they stopped. Other owners, changed sessions, cancellation and read-only restrictions remain enforced. Ordinary and scheduled runs use the same behavior.

- Record reusable workflows explicitly with `/remember TASK`, assign workspace-scoped aliases, and run them with `/task1`. Ordinary tasks are no longer automatically archived or matched. Manage aliases and preferences in Settings.
- Retain structured connection/server identity, IP, operation directory, ordered dependencies and completion criteria for each recorded step. Require fresh observations and a result checkpoint before dependent operations, including across servers. Verification commands remain separate from workflow steps.
- Preflight sudo workflows in their actual execution terminal and refresh an authenticated same-terminal lease during the task. Users enter passwords directly in the terminal; the agent never collects them.
- Update English and Chinese READMEs, guides, twelve-language workflow labels and the bundled model-facing skill. Refresh the editable SVG and PNG illustration for this release, preserving the animated header robot and its reduced-motion fallback.

Validation: bundled skill generation/consistency, TypeScript, 467 local tests (462 passed, five platform skips), production build, whitespace checks, rendered bilingual Markdown, illustration/animation inspection and real npm tarball contents. Branch and tag publication are gated on the GitHub Actions Linux/macOS/Windows matrix.

Limitations: no live Tabby desktop/SSH end-to-end or paid model smoke tests were run. Existing processes with unknown identity still cannot be attached automatically. Semantic completion evidence is evaluated by the model. Sudo refresh requires a compatible POSIX shell/policy; immediate cleanup may be unavailable in an occupied remote terminal without shell integration. Model/tool permission approvals and initial authentication remain separate from terminal takeover.
