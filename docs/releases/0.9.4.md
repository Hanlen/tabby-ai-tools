# v0.9.4

## Conversation navigation and task outcomes

All Agent backends share a question index in the 18px right scrollbar strip, removing the previous left gutter. The scroll thumb supports dragging, wheel input and keyboard navigation; question previews open to the left. Hover or focus to preview, click or press Enter to jump, and use “latest” to resume automatic follow. Theme-aware up/down controls page through long indexes.

Markers use evidence-backed task outcomes. Green means confirmed completion, pale green means an ordinary interruption without user Stop evidence, blue means running or waiting for an external prerequisite, and red means a confirmed Stop, unfinished goal or execution limit. Unknown and legacy failures remain neutral. Completed turns wait for goal observation; stale goal reads cannot overwrite a newer turn. Navigation stores only bounded outcome metadata per local session space, connection, directory and thread; it does not store question text, send messages or replay tools.

## Codex and Claude CLI recovery

New configurations leave the Codex executable field blank; blank and `codex` use identical discovery. A missing or invalid saved entrypoint or unresolved custom command is cleared and persisted before one automatic search. Valid explicit selectors remain preferred. Permission-denied paths, authentication failures, helper/protocol failures and model errors retain their configuration. Cancellation does not clear settings, and late discovery cannot overwrite a newer user edit. Both shared and private Codex clients use the same recovery path; no inference or tool operation is replayed.

Saving a Codex or Claude Code CLI path rechecks idle panels, including private session spaces. Clearing the path uses automatic discovery and restores the saved conversation without sending a message. Changes made during startup or a running turn wait for the next idle boundary. Successful reconnection immediately refreshes the displayed status; installation recovery clears the old connection alert. Claude local retains its independent per-invocation discovery and session-preserving preflight behavior.

Failed connection switches roll back without changing the conversation. Returning to the original connection dismisses only the failed target's diagnostic and preserves newer errors from the active connection.

## Markdown replies and workflow recordings

Assistant replies, restored history and scheduled AI explanations render Markdown tables, headings, lists, quotes, emphasis, links and code. Tables and code scroll within the sidebar. Labeled code fences use bundled syntax highlighting and preserve exact source text for copy. Raw HTML remains escaped, relative file links stay inert, and Markdown images make no automatic network requests.

Recordings preserve complete installation commands and multiline scripts up to the terminal transport's 10,000-character limit. Fixed steps use recorded machine checks. An optional `policy.decision` returns to the main AI before a marked operation that requires live judgment, then resumes verification and later scripted steps without replaying completed operations.
