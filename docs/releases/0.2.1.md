# Tabby AI Tools 0.2.1

## Added

- Twelve bundled interface languages: English, Simplified Chinese, Traditional Chinese, Spanish, French, German, Portuguese, Russian, Japanese, Korean, Arabic, and Hindi.
- Follow Tabby's language or choose an independent preference, with English fallback and right-to-left Arabic layout. User messages, model replies, terminal output, connection names, and model IDs retain their original content.
- Optional automatic sidebar opening when Tabby starts. The setting defaults to off and takes effect on the next launch; hiding the sidebar keeps it hidden for that run.

## Documentation and presentation

- English README with a Simplified Chinese edition and a complete configuration and user guide.
- A provider support table and local ChatGPT subscription setup instructions, with official authentication references.
- Updated guidance for private-network servers, local Codex subscription login, sudo authentication, multi-server orchestration, reusable workflows, and scheduled tasks.
- Expanded bundled Tabby skill routes so models can discover the available tools and user interface entry points.
- A looping robot animation below both README titles, including a static fallback for reduced-motion preferences.
- Public image URLs for README rendering on both GitHub and npm.
- Refreshed SVG and PNG interface illustrations showing multiple SSH terminals, schedules, provider connections, startup settings, and language selection.

## Fixed

- Retry transient file-sharing errors when atomically saving scheduled tasks on Windows, while retaining the old file and bounding persistent failures.
- Make the Linux PTY test prompt deterministic across Bash versions by using a private startup file.
- Handle a process being reaped between the lifecycle test's liveness check and `/proc` read.

## Validation

- Bundled skill consistency, TypeScript checks, production build, and package content checks passed.
- Automated tests: 452 passed, 5 platform-specific tests skipped on Linux.
- GIF frames, looping behavior, static fallback, README asset paths, and SVG/PNG exports were checked.

Some language catalogs started as machine translations and still welcome native-speaker review. The overview is an illustration with example content; live Tabby desktop behavior and appearance have not been newly verified for this release.
